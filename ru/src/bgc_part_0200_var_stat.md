## Переменные

[i[Variables]<]Говорят, что «переменные хранят значения». Но можно
считать, что переменная — это понятное человеку имя, указывающее на
некоторые данные в памяти.

Сейчас мы на секунду заглянем в кроличью нору указателей. Не волнуйтесь.

Можно представлять память как большой массив байтов^[«Байт» обычно
представляет собой 8-битное двоичное число. Думайте о нём как о целом
числе от 0 до 255 включительно. Технически C допускает байты с любым
количеством битов; для однозначного обозначения 8-битного числа следует
использовать термин _октет_. Но программисты обычно понимают под «байтом»
именно 8 битов, если не уточнить обратное.]. Данные хранятся в этом
«массиве»^[Здесь я сильно упрощаю устройство современной памяти. Но
такая модель работает, так что простите мне это упрощение.]. Если число
больше одного байта, оно хранится в нескольких байтах. Поскольку память
похожа на массив, к каждому её байту можно обратиться по индексу. Этот
индекс также называют _адресом_, _местоположением_ или _указателем_.

Когда в C есть переменная, её значение находится _где-то_ в памяти, по
некоторому адресу. Разумеется. Где же ему ещё быть? Но обращаться к
значению по числовому адресу неудобно, поэтому мы даём ему имя — это и
есть переменная.

Я рассказываю обо всём этом по двум причинам:

1. Так будет проще понять переменные-указатели: это переменные, которые
   хранят адреса других переменных!
2. Кроме того, так будет проще понять сами указатели.

Итак, переменная — это имя данных, хранящихся в памяти по определённому
адресу.

### Имена переменных

[i[Variables]<]В именах переменных можно использовать цифры 0–9, буквы
A–Z и a–z, а также подчёркивание, соблюдая следующие правила:

* Имя переменной не может начинаться с цифры 0–9.
* Имя переменной не может начинаться с двух подчёркиваний.
* Имя переменной не может начинаться с подчёркивания, за которым идёт
  заглавная буква A–Z.

С Unicode просто попробуйте. В §D.2 спецификации есть правила о том,
какие диапазоны кодовых точек Unicode разрешены в разных частях
идентификаторов, но здесь это слишком подробно, да и вам, скорее всего,
никогда об этом не придётся задумываться.[i[Variables]>]

### Типы переменных

[i[Types]]В зависимости от того, с какими языками вы уже работали, идея
типов может быть вам знакома или нет. Но C довольно придирчив к типам,
так что освежим знания.

Вот несколько примеров самых простых типов:

[i[`int` type]][i[`float` type]][i[`char` type]][i[`char *` type]]

|Тип|Пример|Тип C|
|:---|------:|:-----|
|Целое число|`3490`|`int`|
|Число с плавающей точкой|`3.14159`|`float`^[Здесь я немного лукавлю. Технически `3.14159` имеет тип `double`, но до этого мы ещё не дошли. Я хочу, чтобы вы связывали `float` с числами с плавающей точкой; C без проблем преобразует значение в `float`. Короче говоря, пока не беспокойтесь об этом.]|
|Одиночный символ|`'c'`|`char`|
|Строка|`"Hello, world!"`|`char *`^[Читайте это как «указатель на `char`» или «указатель `char`». `char` — сокращение от character («символ»). Хотя мне не удалось найти исследование, по личным наблюдениям большинство произносит это как «чар», меньшинство — «кар», а некоторые — «кэр». Об указателях мы поговорим позже.]|

C старается автоматически преобразовывать большинство числовых типов,
если вы его об этом попросите. В остальных случаях преобразования
выполняются вручную — особенно между строками и числами.

Почти все типы в C — разновидности этих типов.

Прежде чем использовать переменную, её нужно _объявить_ и сообщить C,
какие данные она хранит. После объявления тип переменной нельзя изменить
во время выполнения программы. Он остаётся прежним, пока переменная не
выйдет из области видимости и не растворится во Вселенной.

Возьмём наш прежний код «Hello, world» и добавим в него пару переменных:

``` {.c .numberLines}
#include <stdio.h>

int main(void)
{
    int i;    // Хранит целые числа со знаком, например -3, -2, 0, 1, 10
    float f;  // Хранит числа с плавающей точкой и знаком, например -3.1416

    printf("Hello, World!\n");  // Ах, как же это знакомо
}
```

Вот! Мы объявили пару переменных. Пока мы их не использовали, и обе они
не инициализированы. Одна хранит целое число, другая — число с плавающей
точкой (по сути, действительное число, если вы знакомы с математикой).

[i[Variables-->uninitialized]]Неинициализированные переменные имеют
неопределённое значение^[В разговоре мы говорим, что в них «случайные»
значения, но на самом деле это не случайные и даже не псевдослучайные
числа.]. Их нужно инициализировать; иначе считайте, что в них хранится
какая-то ерунда.

> Здесь C может вас подловить. По моему опыту, неопределённое значение
> часто равно нулю… но при каждом запуске оно может меняться! Никогда не
> считайте, что значение будет нулевым, даже если видите именно ноль.
> _Всегда_ явно инициализируйте переменные каким-нибудь значением до
> использования^[Это не совсем на 100% верно. Когда мы дойдём до
> длительности статического хранения, вы узнаете, что некоторые
> переменные автоматически инициализируются нулём. Но безопаснее всегда
> инициализировать их самостоятельно.].

Что такое? Хотите сохранить числа в этих переменных? Безумие!

Давайте так и поступим:
[i[`=` assignment operator]]

``` {.c .numberLines}
int main(void)
{
    int i;

    i = 2; // Присваиваем переменной i значение 2

    printf("Hello, World!\n");
}
```

Отлично. Мы сохранили значение. Давайте его выведем.

[i[`printf()` function]<]Для этого мы передадим функции `printf()` целых
два аргумента. Первый — строка, описывающая, что и как вывести (она
называется _форматной строкой_), второй — выводимое значение, то есть
содержимое переменной `i`.

`printf()` ищет в форматной строке специальные последовательности,
начинающиеся со знака процента (`%`), которые указывают, что выводить.
Например, встретив `%d`, функция берёт следующий переданный параметр и
выводит его как целое число. `%f` означает вывести значение как число с
плавающей точкой, а `%s` — вывести строку.

Таким образом, значения разных типов можно выводить так:

``` {.c .numberLines}
#include <stdio.h>

int main(void)
{
    int i = 2;
    float f = 3.14;
    char *s = "Hello, world!";  // char * («указатель на char») — строковый тип

    printf("%s  i = %d and f = %f!\n", s, i, f);
}
```

Результат будет таким:

``` {.default}
Hello, world!  i = 2 and f = 3.14!
```

В этом отношении `printf()` похожа на форматные или параметризованные
строки из других знакомых вам языков.  [i[`printf()` function]>]

***ПРИМЕЧАНИЕ:*** В следующих разделах я буду считать, что переменные
уже объявлены. Если в примере используются целые `i` и `j`, считайте,
что где-то выше было написано:

``` {.c}
int i, j;
```

### Логические типы

[i[Boolean types]<]В C есть логические типы — истина или ложь?

`1`!

Исторически в C не было логического типа, и некоторые скажут, что его
нет до сих пор.

В C `0` означает «ложь», а любое ненулевое значение — «истину».

Значит, `1` — истина. И `-37` — истина. А `0` — ложь.

Логические значения можно просто объявлять как `int`:

``` {.c}
int x = 1;

if (x) {
    printf("x is true!\n");
}
```

В C23 появились настоящие `bool`, `true` и `false`. В более ранних
версиях C, если компилятор достаточно современный, подключите
`#include <stdbool.h>`[i[`stdbool.h` header file]], чтобы получить то же.

``` {.c .numberLines}
#include <stdio.h>
#include <stdbool.h>  // в C23 не требуется

int main(void) {
    bool x = true;

    if (x) {
        printf("x is true!\n");
    }
}
```

Технически переменной `bool` следует присваивать `true`, `false` или
результат выражения, вычисляющегося в истину либо ложь. Но преобразовать
в `bool` можно самые разные значения. Есть конкретные правила, но
значения, близкие к нулю, обычно дают `false`, а ненулевые — `true`.

Будьте осторожны при смешивании типов: числовое значение `true`, скорее
всего, равно `1`[^B1CA], поэтому ожидание, что любое другое положительное
число равно именно `true`, может привести к несоответствию. Например:

``` {.c .numberLines}
printf("%d\n", true == 12);  // Выводит «0», то есть false!
```

[^B1CA]: Технически для представления `bool` используется лишь один бит
    `char`, поэтому он может быть нулём или единицей. Однако содержимое
    остальных (заполняющих) битов `char` не определено. Для `false` они,
    конечно, должны быть нулевыми. А вот для `true` я не уверен, что они
    обязательно все нулевые.

[i[Boolean types]>]

## Операторы и выражения {#operators}

C-операторы должны быть вам знакомы по другим языкам. Быстро рассмотрим
некоторые из них.

(Подробностей гораздо больше, но для начала в этом разделе хватит и
этого.)


### Арифметика

[i[Arithmetic Operators]()]Надеюсь, эти операторы вам знакомы:
[i[`+` addition operator]] [i[`-` subtraction operator]]
[i[`*` multiplication operator]] [i[`/` division operator]]
[i[`%` modulus operator]]

``` {.c}
i = i + 3;  // Операторы сложения (+) и присваивания (=), прибавляем к i 3
i = i - 8;  // Вычитание: вычитаем из i 8
i = i * 9;  // Умножение
i = i / 2;  // Деление
i = i % 5;  // Остаток от деления
```

Для всех перечисленных операторов есть сокращённые варианты. Каждую из
этих строк можно записать короче:
[i[`+=` assignment operator]] [i[`-=` assignment operator]]
[i[`*=` assignment operator]] [i[`/=` assignment operator]]
[i[`%=` assignment operator]]

``` {.c}
i += 3;  // То же, что "i = i + 3": прибавляем к i 3
i -= 8;  // То же, что "i = i - 8"
i *= 9;  // То же, что "i = i * 9"
i /= 2;  // То же, что "i = i / 2"
i %= 5;  // То же, что "i = i % 5"
```

Оператора возведения в степень нет. Для этого используйте один из
вариантов функции `pow()`[i[pow()]T] из `math.h`.

Перейдём к более необычным вещам, которых может не быть в других ваших
языках![i[Arithmetic Operators]>]

### Тернарный оператор

[i[`?:` ternary operator]<]В C есть и _тернарный оператор_. Это
выражение, значение которого зависит от результата встроенного в него
условия.

``` {.c}
// Если x > 10, прибавить к y 17. Иначе прибавить к y 37.

y += x > 10? 17: 37;
```

Какой беспорядок! Чем чаще будете это видеть, тем привычнее станет. Для
наглядности перепишу выражение с помощью `if`:

``` {.c}
// Это выражение:

y += x > 10? 17: 37;

// эквивалентно этому невыражению:

if (x > 10)
    y += 17;
else
    y += 37;
```

Сравните эти два варианта, чтобы увидеть все части тернарного оператора.

И ещё пример: выводим, является ли число в `x` чётным или нечётным:

``` {.c}
printf("The number %d is %s.\n", x, x % 2 == 0? "even": "odd");
```

Спецификатор формата `%s` в `printf()`[i[printf()]T] означает вывод
строки. Если выражение `x % 2` даёт `0`, всё тернарное выражение даёт
строку `"even"`. Иначе результатом будет строка `"odd"`. Здорово!

Важно понимать, что тернарный оператор не управляет потоком выполнения,
как инструкция `if`. Это просто выражение, вычисляющее значение.
[i[`?:` ternary operator]>]

### Префиксный и постфиксный инкремент и декремент

[i[`++` increment operator]<] [i[`--` decrement operator]<]
Теперь разберём ещё одну вещь, которую вы, возможно, не встречали.

Это легендарные операторы постфиксного инкремента и декремента:

``` {.c}
i++;        // Увеличить i на единицу (постфиксный инкремент)
i--;        // Уменьшить i на единицу (постфиксный декремент)
```

Чаще всего их используют просто как сокращённую запись:

``` {.c}
i += 1;        // Увеличить i на единицу
i -= 1;        // Уменьшить i на единицу
```

но между ними есть более тонкое различие, хитрецы.

Рассмотрим варианты с префиксным инкрементом и декрементом:

``` {.c}
++i;        // Увеличить i на единицу (префиксный инкремент)
--i;        // Уменьшить i на единицу (префиксный декремент)
```

При префиксном инкременте или декременте значение переменной
увеличивается или уменьшается _до_ вычисления выражения. Затем выражение
вычисляется уже с новым значением.

При постфиксном инкременте или декременте сначала вычисляется значение
выражения с текущим значением переменной, и лишь _затем_ переменная
увеличивается или уменьшается.

Их можно включать в выражения, например так:

``` {.c}
i = 10;
j = 5 + i++;  // Вычислить 5 + i, _затем_ увеличить i

printf("%d, %d\n", i, j);  // Выводит 11, 15
```

Сравним это с префиксным инкрементом:

``` {.c}
i = 10;
j = 5 + ++i;  // Увеличить i, _затем_ вычислить 5 + i

printf("%d, %d\n", i, j);  // Выводит 11, 16
```

Этот приём часто используют при обращении к массивам и указателям и при
работе с ними. Он позволяет использовать значение переменной и
одновременно увеличить или уменьшить его до или после использования.

Но чаще всего вы встретите его в цикле `for`:

``` {.c}
for (i = 0; i < 10; i++)
    printf("i is %d\n", i);
```

Но об этом позже.
[i[`++` increment operator]>] [i[`--` decrement operator]>]

### Оператор запятая

[i[`,` comma operator]<]
Это редко используемый способ разделить выражения, которые выполняются
слева направо:

``` {.c}
x = 10, y = 20;  // Сначала присвоить x значение 10, затем y значение 20
```

Кажется немного глупым: ведь запятую можно заменить точкой с запятой,
верно?

``` {.c}
x = 10; y = 20;  // Сначала присвоить x значение 10, затем y значение 20
```

Но это немного другое. Во втором случае два отдельных выражения, а в
первом — одно!

При использовании оператора запятая значение всего выражения равно
значению самого правого выражения:

``` {.c}
x = (1, 2, 3);

printf("x is %d\n", x);  // Выводит 3, потому что в списке через запятую 3 стоит последним
```

Но и это довольно искусственный пример. Часто оператор запятая
используется в циклах `for`, чтобы выполнять несколько действий в каждой
части инструкции:

``` {.c}
for (i = 0, j = 10; i < 100; i++, j++)
    printf("%d, %d\n", i, j);
```

Мы ещё вернёмся к этому.
[i[`,` comma operator]>]

### Условные операторы

[i[Conditional Operators]<]
Для логических значений есть целый набор стандартных операторов:
[i[Comparison operators]] [i[`==` equality operator]]
[i[`!=` inequality operator]] [i[`<` less than operator]]
[i[`>` greater than operator]] [i[`<=` less or equal operator]]
[i[`>=` greater or equal operator]]

``` {.c}
a == b;  // Истина, если a равно b
a != b;  // Истина, если a не равно b
a < b;   // Истина, если a меньше b
a > b;   // Истина, если a больше b
a <= b;  // Истина, если a меньше или равно b
a >= b;  // Истина, если a больше или равно b
```

Не путайте присваивание (`=`) со сравнением (`==`)! Для сравнения нужны
два знака равенства, для присваивания — один.

Выражения сравнения можно использовать в инструкциях `if`:

``` {.c}
if (a <= 10)
    printf("Success!\n");
```
[i[Conditional Operators]>]

### Логические операторы

[i[Boolean Operators]<]
Логическими операторами _и_, _или_ и _не_ можно объединять условия или
изменять их.
[i[`&&` boolean AND]]
[i[`!` boolean NOT]]
[i[`||` boolean OR]]

|Оператор|Логическое значение|
|:------:|:-------------:|
|`&&`|и|
|`||`|или|
|`!`|не|

Пример логического «и»:

``` {.c}
// Выполнить действие, если x меньше 10, а y больше 20:

if (x < 10 && y > 20)
    printf("Doing something!\n");
```

Пример логического «не»:

``` {.c}
if (!(x < 12))
    printf("x is not less than 12\n");
```

У `!` приоритет выше, чем у остальных логических операторов, поэтому в
этом случае нужны скобки.

Конечно, это то же самое, что:

``` {.c}
if (x >= 12)
    printf("x is not less than 12\n");
```

но мне нужен был пример!
[i[Boolean Operators]>]

### Оператор `sizeof` {#sizeof-operator}

[i[`sizeof` operator]<]
Этот оператор сообщает, сколько места (в байтах) занимает в памяти
конкретная переменная или тип данных.

Точнее, он сообщает, сколько места (в байтах) занимает в памяти _тип
конкретного выражения_ (которым может быть всего лишь одна переменная).

На разных системах этот размер может различаться, за исключением `char`[i[`char`
type]] и его вариантов (они всегда занимают 1 байт).

Сейчас это может показаться не очень полезным, но мы будем время от
времени к этому обращаться, поэтому стоит разобрать оператор.

Поскольку оператор вычисляет количество байтов, нужных для хранения
типа, можно подумать, что он возвращает `int`. Или… раз размер не может
быть отрицательным, может быть, `unsigned`?

[i[`size_t` type]<]
Но в C есть специальный тип для значения, возвращаемого `sizeof`. Это
`size_t`, произносится «сайз ти»^[`_t` — сокращение от `type`.]. Мы знаем
лишь, что это беззнаковый целочисленный тип, способный хранить размер в
байтах любого объекта, который можно передать `sizeof`.

`size_t` часто встречается там, где передают или возвращают количество
чего-либо. Считайте его типом для хранения счётчика.
[i[`size_t` type]>]

Можно узнать `sizeof` переменной или выражения:

``` {.c}
int a = 999;

// %zu — спецификатор формата для типа size_t
// Если компилятор не принимает часть "z", уберите её

printf("%zu\n", sizeof a);      // В моей системе выводит 4
printf("%zu\n", sizeof(2 + 7)); // В моей системе выводит 4
printf("%zu\n", sizeof 3.14);   // В моей системе выводит 8

// Чтобы выводить отрицательные значения size_t, используйте %zd
```

Помните: это размер в байтах _типа_ выражения, а не самого выражения.
Поэтому размер `2+7` такой же, как размер `a`: оба имеют тип `int`. К
числу `4` мы вернёмся уже в следующем фрагменте кода…

…где увидим, что можно узнать `sizeof` типа (обратите внимание: имя типа,
в отличие от выражения, обязательно нужно заключать в скобки):

``` {.c}
printf("%zu\n", sizeof(int));   // В моей системе выводит 4
printf("%zu\n", sizeof(char));  // Во всех системах выводит 1
```

Важно отметить, что `sizeof` — это операция времени компиляции^[За
исключением массивов переменной длины, но это тема для другого раза.].
Результат выражения определяется целиком во время компиляции, а не
выполнения программы.

Позже мы этим воспользуемся.
[i[`sizeof` operator]>]


## Управление потоком выполнения

[i[Flow Control]<]
Логические значения — это хорошо, но без управления ходом программы мы
далеко не уйдём. Рассмотрим несколько конструкций: `if`, `for`, `while`
и `do-while`.

Сначала — небольшое замечание на будущее об инструкциях и блоках от
вашего дружелюбного местного разработчика на C:

После такой инструкции, как `if` или `while`, можно написать одну
инструкцию либо блок инструкций, которые будут выполнены по порядку.

[i[`if` statement]<]
Начнём с одной инструкции:

``` {.c}
if (x == 10) printf("x is 10\n");
```

Иногда её записывают и на отдельной строке. (В C пробелы почти ни на что
не влияют — в отличие от Python.)

``` {.c}
if (x == 10)
    printf("x is 10\n");
```

А если по условию нужно выполнить несколько действий? Фигурными скобками
можно обозначить _блок_ или _составную инструкцию_.

``` {.c}
if (x == 10) {
    printf("x is 10\n");
    printf("And also this happens when x is 10\n");
}
```

Очень распространённый стиль — _всегда_ использовать фигурные скобки,
даже если они не обязательны:

``` {.c}
if (x == 10) {
    printf("x is 10\n");
}
```

Некоторые разработчики считают, что так код проще читать и удаётся
избежать ошибок вроде этой: визуально кажется, будто строки находятся в
блоке `if`, хотя на самом деле это не так.

``` {.c}
// ПЛОХОЙ ПРИМЕР ОШИБКИ

if (x == 10)
    printf("This happens if x is 10\n");
    printf("This happens ALWAYS\n");  // Сюрприз! Выполняется всегда!
```

`while`, `for` и другие циклические конструкции работают так же, как в
примерах выше. Если в цикле или после `if` нужно сделать несколько дел,
заключите их в фигурные скобки.

Иными словами, `if` выполняет следующую за ним конструкцию. Это может
быть отдельная инструкция или блок инструкций.
[i[`if` statement]>]


### Инструкция `if`-`else` {#ifstat}

[i[`if`-`else` statement]<]
Мы уже использовали `if` в нескольких примерах — скорее всего, вы
встречали эту конструкцию и раньше. Вот ещё один пример:

``` {.c}
int i = 10;

if (i > 10) {
    printf("Yes, i is greater than 10.\n");
    printf("And this will also print if i is greater than 10.\n");
}

if (i <= 10) printf("i is less than or equal to 10.\n");
```

В этом примере сообщение выводится, если `i` больше 10; иначе выполнение
переходит к следующей строке. Обратите внимание на фигурные скобки после
`if`: если условие истинно, выполняется либо первая инструкция или
выражение сразу после `if`, либо весь блок кода в скобках. Такое
поведение _блоков кода_ свойственно всем инструкциям.

Конечно, в C можно задать и действие на случай, когда условие ложно,
добавив к `if` ветку `else`:

``` {.c}
int i = 99;

if (i == 10)
    printf("i is 10!\n");
else {
    printf("i is decidedly not 10.\n");
    printf("Which irritates me a little, frankly.\n");
}
```

Можно даже выстроить их цепочкой, чтобы проверить разные условия:

``` {.c}
int i = 99;

if (i == 10)
    printf("i is 10!\n");

else if (i == 20)
    printf("i is 20!\n");

else if (i == 99) {
    printf("i is 99! My favorite\n");
    printf("I can't tell you how happy I am.\n");
    printf("Really.\n");
}
    
else
    printf("i is some crazy number I've never heard of.\n");
```

Если выберете такой подход, взгляните на инструкцию
[`switch`](#switch-statement): возможно, она подойдёт лучше. Но `switch`
работает только со сравнением на равенство с константными числами. В
цепочке `if`-`else` выше можно проверять неравенство, диапазоны,
переменные и любые другие условия, которые можно выразить условным
выражением.
[i[`if`-`else` statement]>]

### Инструкция `while` {#whilestat}

[i[`while` statement]<]
`while` — обычная циклическая конструкция. Выполняйте действие, пока
условное выражение истинно.

Давайте напишем такой цикл!

``` {.c}
// Вывести следующий текст:
//
//   Теперь i равно 0!
//   Теперь i равно 1!
//   [ далее то же самое для значений от 2 до 7 ]
//   Теперь i равно 8!
//   Теперь i равно 9!

int i = 0;

while (i < 10) {
    printf("i is now %d!\n", i);
    i++;
}

printf("All done!\n");
```

Вот и простой цикл. В C есть также цикл `for`, который в этом примере
смотрелся бы аккуратнее.

Нередко `while` используют для бесконечных циклов, которые повторяются,
пока условие истинно:

``` {.c}
while (1) {
    printf("1 is always true, so this repeats forever.\n");
}
```
[i[`while` statement]>]


### Инструкция `do-while` {#dowhilestat}

[i[`do`-`while` statement]<]
Теперь, когда мы разобрались с `while`, посмотрим на его близкого
родственника — `do-while`.

В целом они одинаковы, но если условие цикла ложно с самого начала,
`do-while` выполнится один раз, а `while` не выполнится вовсе. Иными
словами, в `do-while` проверка необходимости выполнить блок происходит в
_конце_ блока, а в `while` — в _начале_.

Посмотрим на примере:

``` {.c}
// Используя цикл while:

i = 10;

// этот код не выполнится, потому что i не меньше 10:
while(i < 10) {
    printf("while: i is %d\n", i);
    i++;
}

// Используя цикл do-while:

i = 10;

// этот код выполнится один раз, потому что условие цикла проверяется лишь
// после выполнения тела цикла:

do {
    printf("do-while: i is %d\n", i);
    i++;
} while (i < 10);

printf("All done!\n");
```

Обратите внимание: в обоих случаях условие цикла сразу ложно. Поэтому
цикл `while` завершается, и следующий за ним блок кода не выполняется.
В `do-while` условие проверяется _после_ выполнения блока, поэтому блок
выполняется хотя бы один раз. Здесь программа выводит сообщение,
увеличивает `i`, затем получает ложное условие и переходит к выводу
«All done!».

Вывод такой: если цикл должен выполниться хотя бы один раз независимо от
условия, используйте `do-while`.

Все эти примеры, возможно, лучше было бы написать с циклом `for`. А
теперь сделаем что-нибудь менее предсказуемое: будем повторять цикл, пока
не выпадет определённое случайное число!

``` {.c .numberLines}
#include <stdio.h>   // Для printf
#include <stdlib.h>  // Для rand

int main(void)
{
    int r;

    do {
        r = rand() % 100; // Получить случайное число от 0 до 99
        printf("%d\n", r);
    } while (r != 37);    // Повторять, пока не выпадет 37
}
```

Кстати, вы запускали этот код несколько раз? Заметили, что снова и снова
появляется одна и та же последовательность чисел? Дело в том, что
`rand()` — генератор псевдослучайных чисел. Чтобы получить другую
последовательность, его нужно _инициализировать_ другим числом. Подробности
смотрите в описании функции
[fl[`srand()`|https://beej.us/guide/bgclr/html/split/stdlib.html#man-srand]]
для получения дополнительной информации. [i[`do`-`while` statement]>]

### Инструкция `for` {#forstat}

[i[`for` statement]<]
Добро пожаловать к одному из самых популярных циклов в мире! Циклу
`for`!

Этот цикл отлично подходит, если заранее известно, сколько раз нужно
повторить действие.

То же самое можно сделать с помощью `while`, но `for` помогает сохранить
код более аккуратным.

Вот два равнозначных фрагмента кода. Обратите внимание, что цикл `for` —
просто более компактная запись:

``` {.c}
// Вывести числа от 0 до 9 включительно...

// Используя цикл while:

i = 0;
while (i < 10) {
    printf("i is %d\n", i);
    i++;
}

// Сделать ровно то же самое с помощью цикла for:

for (i = 0; i < 10; i++) {
    printf("i is %d\n", i);
}
```

Именно так: они делают одно и то же. Но видно, что инструкция `for`
немного компактнее и легче для восприятия. (Пользователи JavaScript
сейчас особенно оценят его происхождение из C.)

Цикл состоит из трёх частей, разделённых точками с запятой. Первая —
инициализация, вторая — условие продолжения цикла, третья — действие,
которое выполняется в конце блока, если условие истинно. Все три части
необязательны.

``` {.c}
for (initialize things; loop if this is true; do this after each loop)
```

Обратите внимание: если условие цикла изначально ложно, цикл не выполнится
ни разу.

> **Забавный факт о цикле `for`!**
>
> В каждой части цикла `for` можно использовать оператор запятая, чтобы
> выполнить несколько действий!
>
> ``` {.c}
> for (i = 0, j = 999; i < 10; i++, j--) {
>     printf("%d, %d\n", i, j);
> }
> ```

<!-- ` -->
Пустой цикл `for` будет выполняться бесконечно:

``` {.c}
for(;;) {  // «бесконечно»
    printf("I will print this again and again and again\n" );
    printf("for all eternity until the heat-death of the universe.\n");

    printf("Or until you hit CTRL-C.\n");
}
```
[i[`for` statement]>]

### Инструкция `switch` {#switch-statement}

[i[`switch` statement]<]
В зависимости от того, на каких языках вы программировали, инструкция
`switch` может быть вам знакома, а версия в C — даже более ограниченной,
чем вы привыкли. Она позволяет выбирать действие в зависимости от
значения целочисленного выражения.

По сути, инструкция вычисляет выражение до целочисленного значения и
переходит к соответствующему этому значению варианту
[i[`case` statement]<]`case`. Выполнение продолжается с этого места. Если
встречается инструкция `break`[i[`break` statement]<], выполнение выходит
из `switch`.

Вот пример: по заданному количеству коз мы выводим свою оценку того,
насколько это много.

``` {.c .numberLines}
#include <stdio.h>

int main(void)
{
    int goat_count = 2;

    switch (goat_count) {
        case 0:
            printf("You have no goats.\n");
            break;

        case 1:
            printf("You have a singular goat.\n");
            break;

        case 2:
            printf("You have a brace of goats.\n");
            break;

        default:
            printf("You have a bona fide plethora of goats!\n");
            break;
    }
}
```

В этом примере `switch` перейдёт к `case 2` и начнёт выполнение оттуда.
Когда (если) встретится `break`, выполнение выйдет из `switch`.
[i[`break` statement]>]

Внизу также можно увидеть метку `default`[i[`default` label]]. Она
определяет, что делать, если ни один вариант не совпал.

Каждый `case`, включая `default`, необязателен. Они могут идти в любом
порядке, но обычно `default`, если он есть, ставят последним.[i[`case` statement]>]

Таким образом, вся конструкция работает примерно как цепочка
`if`-`else`:

``` {.c}
if (goat_count == 0)
    printf("You have no goats.\n");
else if (goat_count == 1)
    printf("You have a singular goat.\n");
else if (goat_count == 2)
    printf("You have a brace of goats.\n");
else
    printf("You have a bona fide plethora of goats!\n");
```

Но есть несколько важных отличий:

* `switch` часто быстрее переходит к нужному коду (хотя спецификация
  этого не гарантирует).
* В `if`-`else` можно использовать условия отношений вроде `<` и `>=`, а
  также числа с плавающей точкой и другие типы; `switch` этого не умеет.

Есть ещё одна интересная особенность `switch`, которую иногда можно
встретить: _проваливание_ в следующий вариант (_fall through_).

[i[`break` statement]<]
Помните, что `break` заставляет нас выйти из `switch`?

[i[Fall through]<]
А что произойдёт, если _не_ написать `break`?

Оказывается, выполнение просто продолжится в следующем `case`! Смотрите:

``` {.c}
switch (x) {
    case 1:
        printf("1\n");
        // Переход к следующему случаю!
    case 2:
        printf("2\n");
        break;
    case 3:
        printf("3\n");
        break;
}
```

Если `x == 1`, `switch` сначала попадёт в `case 1` и выведет `1`, но
затем продолжит выполнять следующую строку кода… которая выведет `2`!

Наконец, мы дойдём до `break` и выйдем из `switch`.

Если `x == 2`, мы сразу попадём в `case 2`, выведем `2` и выполним
`break`, как обычно.

Отсутствие `break` называется _проваливанием_ (_fall through_).

Если вы используете стандарт до C23, _ВСЕГДА_ оставляйте в коде
комментарий там, где намеренно допускаете проваливание, как в примере
выше. Тогда другие программисты не будут гадать, задумано ли это. GCC
распознаёт такие комментарии и подавляет предупреждения.

Можно использовать нестандартный атрибут GCC. Он мне никогда не нравился:
выглядит некрасиво и не входит в стандарт, хотя его распознают и GCC, и
Clang:

``` {.c}
switch (x) {
    case 1:
        printf("1\n");
        __attribute__((fallthrough));
    case 2:
        ...
```

Но наконец в C23 появился стандартный способ сделать это с помощью
атрибутов:

``` {.c}
switch (x) {
    case 1:
        printf("1\n");
        [[fallthrough]];
    case 2:
        ...
```

Но помните: здесь часто возникают ошибки в программах на C — например,
если забыть поставить `break` в `case`. Добавляйте его, если не хотите,
чтобы выполнение провалилось в следующий вариант[^19a1].

[^19a1]: Это считалось настолько опасным, что создатели языка Go сделали
    `break` поведением по умолчанию. Чтобы перейти к следующему варианту,
    нужно явно использовать инструкцию `fallthrough` из Go.

[i[Fall through]>]
[i[`break` statement]>]

Ранее я говорил, что `switch` работает с целочисленными типами, — так и
используйте его. Не применяйте здесь числа с плавающей точкой или строки.
Есть небольшое исключение: можно использовать символьные типы, поскольку
по сути это тоже целые числа. Поэтому такой код вполне допустим:

``` {.c}
char c = 'b';

switch (c) {
    case 'a':
        printf("It's 'a'!\n");
        break;

    case 'b':
        printf("It's 'b'!\n");
        break;

    case 'c':
        printf("It's 'c'!\n");
        break;
}
```

Наконец, в `switch` можно использовать [i[`enum` keyword]]типы `enum`,
поскольку они тоже целочисленные. Но об этом подробнее — в главе про
`enum`.

[i[`switch` statement]>] [i[`break` statement]>] [i[Flow Control]>]
