# Руководство Beej по языку C

Здесь находятся исходные материалы руководства Beej по языку C.

Если вы хотите просто прочитать руководство, посетите сайт [Beej's Guide to C](https://beej.us/guide/bgc/).

Репозиторий нужен, чтобы у Beej были собраны все материалы, а переводчики могли легко получить их копию.

## Сборка

### Зависимости

* [GNU Make](https://www.gnu.org/software/make/) (подойдёт и Make из Xcode)
* [Python 3 или новее](https://www.python.org/)
* [Pandoc 2.7.3 или новее](https://pandoc.org/)
* XeLaTeX (входит в [TeX Live](https://www.tug.org/texlive/))
* [Шрифты Liberation](https://en.wikipedia.org/wiki/Liberation_fonts) (sans, serif и mono)

Установка зависимостей на Mac (после установки перезапустите терминал):

```
xcode-select --install                  # устанавливает make
brew install python                     # устанавливает Python 3
brew install pandoc
brew install mactex                     # устанавливает XeLaTeX
brew tap homebrew/cask-fonts
brew install font-liberation            # устанавливает шрифты Liberation
```

Чтобы система находила `xelatex`, возможно, потребуется добавить его каталог в `PATH`, например:

```
PATH=$PATH:/usr/local/texlive/2021/bin/universal-darwin
```

### Система сборки

Для сборки требуется внешний проект [Beej's Guide Build System for Pandoc](https://github.com/beejjorgensen/bgbspd).

Клонируйте его в каталог рядом с этим репозиторием:

```
mystuff-->bggit
      \-->bgbspd
```

Файлы Makefile в этом репозитории будут искать систему сборки в соседнем каталоге.

Перед запуском `make` можно указать другой каталог `bgbspd`:

```
export BGBSPD_BUILD_DIR=/some/path/to/bgbspd
```

### Сборка русского перевода

Перейдите в каталог `ru` и запустите сборку:

```
cd ru
make
```

Результаты сборки появятся в `ru/src/`: HTML-файлы, разделённая HTML-версия и PDF-файлы. Для удаления временных результатов выполните `make clean`, а для полной очистки — `make pristine` (также из каталога `ru`).

### Сборка проекта

1. Выполните `make` из корневого каталога репозитория.

   Рекомендуется использовать GNU Make, но могут подойти и другие версии Make. В Windows можно воспользоваться Cygwin.

2. Выполните `make stage`, чтобы скопировать все результаты сборки и сайт в каталог `stage`.

3. Третьего шага нет.

Сборку также можно запустить из каталога `src` командой `make`.

Команда `make clean` удаляет результаты сборки, а `make pristine` возвращает исходное состояние.

Примеры встраивания собственных шрифтов в PDF приведены в `src/Makefile`.

Цель `upload` в корневом `Makefile` показывает шаги сборки полного выпуска. Чтобы использовать её, измените макрос `UPLOADDIR` в корневом `Makefile`, указав каталог на своём сервере. Отдельные версии руководства также можно загружать по своему усмотрению.
